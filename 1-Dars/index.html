JavaScriptga kirish

Bu yerda JavaScript asoslari haqida ma'lumot beriladi.

JavaScript nima?

JavaScript - bu veb-sahifalarni interaktiv qilish uchun ishlatiladigan dasturlash tili.

JavaScript qanday ishlaydi?

JavaScript brauzerda ishlaydi va foydalanuvchi bilan o'zaro aloqada bo'lish imkonini beradi.

JavaScript kodini qanday yozish mumkin?

JavaScript kodini HTML faylida <script> teglar ichida yozish mumkin.
