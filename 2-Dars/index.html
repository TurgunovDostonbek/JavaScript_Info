Javascript da O'zgaruvchilar

Javascript dasturlash tilida o'zgaruvchilar ma'lumotlarni saqlash uchun ishlatiladi. O'zgaruvchilarni yaratish uchun let, const yoki var kalit so'zlaridan foydalanamiz.

O'zgaruvchilarni e'lon qilish

O'zgaruvchilarni e'lon qilish uchun quyidagi sintaksisdan foydalanamiz:

let ism = "Ali";

Yuqoridagi misolda ism o'zgaruvchisi Ali qiymatini oladi.
